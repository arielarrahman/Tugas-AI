## Deskripsi Repository

Repository ini berisi kumpulan tugas mata kuliah **Kecerdasan Artifisial (Artificial Intelligence/AI)** pada Program Studi Geofisika, Universitas Hasanuddin.

Repository ini digunakan sebagai dokumentasi tugas perkuliahan yang membahas penerapan konsep, metode, dan algoritma kecerdasan artifisial melalui pemrograman Python. Materi tugas disesuaikan dengan topik dan tujuan analisis masing-masing, termasuk penerapan AI untuk menyelesaikan permasalahan yang berkaitan dengan bidang geofisika.

Setiap tugas disusun dalam bentuk notebook Python (`.ipynb`) yang memuat tahapan analisis, implementasi kode, visualisasi, serta interpretasi hasil sesuai dengan kebutuhan masing-masing tugas.

## Tujuan

- Mendokumentasikan pengerjaan tugas mata kuliah Kecerdasan Artifisial.
- Memahami penerapan algoritma AI melalui pemrograman Python.
- Menerapkan metode kecerdasan artifisial untuk analisis dan penyelesaian masalah.
- Mengembangkan pemahaman mengenai pemanfaatan AI dalam bidang geofisika.
